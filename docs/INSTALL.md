# Установка NETWATCH//TERMINAL

[← На главную](../README.md) · [Скриншоты](SCREENSHOTS.md) · [Возможности](FEATURES.md)

## Что потребуется

- Для готовой сборки: Windows 10/11, 64-битный процессор, аккаунт GitHub для скачивания артефакта.
- Для запуска исходников: Python 3.12 или новее, 64-битный. Команды ниже используют конкретно Python 3.12.
- Интернет для скачивания приложения и зависимостей; после установки интерфейс работает локально.
- Права администратора для запуска приложения не нужны.

Это приложение для компьютера. На Android/iPhone можно просматривать репозиторий и картинки, но нельзя запускать Windows `.exe` или PySide6-приложение.

## Способ 1. Готовое приложение для Windows — без Python

1. Войдите в свой аккаунт GitHub.
2. Откройте [список сборок Desktop checks](https://github.com/PANDORA615/Netwatch-Terminal/actions/workflows/ci.yml).
3. Найдите свежий **успешный** запуск ветки `main` с зелёной галочкой и откройте его. Если стоит жёлтый значок — дождитесь завершения. Красный крест означает, что сборка не прошла.
4. Прокрутите страницу до **Artifacts**. Нужен **NetwatchTerminal-Windows-x64**, а не `preview-Windows` (это только скриншот).
5. Скачайте архив. Если артефактов нет, проверьте вход в GitHub и выберите другой успешный запуск: старые артефакты могут истечь.
6. В Проводнике нажмите ZIP правой кнопкой → **Извлечь всё**. Например, выберите папку `Документы\NetwatchTerminal`.
7. Откройте распакованную папку и дважды нажмите `NetwatchTerminal.exe`.

**Не удаляйте `_internal` и другие файлы рядом с `.exe`.** Это переносимая папка приложения, а не одиночный исполняемый файл. Отдельного установщика пока нет. При предупреждении Windows проверьте источник и сведения о файле; подпись издателя пока не настроена.

Обновление: скачайте новый успешный артефакт и распакуйте в новую папку. Удаление: закройте приложение и удалите распакованную папку.

## Способ 2. Из исходников в Windows — без Git

### 1. Установите Python

Откройте [python.org — Windows](https://www.python.org/downloads/windows/), скачайте установщик Python 3.12 **64-bit**. При установке включите **Add python.exe to PATH** и Python Launcher. После установки закройте и снова откройте терминал.

В PowerShell проверьте:

```powershell
py -3.12 --version
```

Ожидается `Python 3.12.x`. Если вы установили, например, 3.13, используйте `py -3.13` вместо `py -3.12` в командах создания окружения.

### 2. Скачайте код

На [странице репозитория](https://github.com/PANDORA615/Netwatch-Terminal) нажмите **Code → Download ZIP**, затем **Извлечь всё**. Откройте папку `Netwatch-Terminal-main`. В ней должны лежать `pyproject.toml`, `README.md` и папка `src`.

Нажмите правой кнопкой в пустом месте этой папки → **Открыть в Терминале** и выберите PowerShell. Все дальнейшие команды выполняются здесь.

### 3. Установите зависимости

Выполните по одной команде и дождитесь завершения каждой:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -e .
```

Первая команда создаёт отдельное окружение `.venv`. Последняя устанавливает приложение и библиотеки, включая PySide6; скачивание может занять несколько минут. Активация окружения через `Activate.ps1` не нужна.

### 4. Запустите окно

```powershell
.\.venv\Scripts\python.exe -m netwatch_terminal
```

Должно открыться окно NETWATCH с выбранным разделом Terminal. На следующих запусках нужна только эта команда из той же папки.

### 5. Проверьте интерфейс

Выберите Fedora или Arch Linux — приглашение и подсказки должны измениться. Введите текст и нажмите Enter: появится уведомление о предпросмотре. Переключите Dashboard и вернитесь в Terminal. **Команды в текущей версии не выполняются**, Dashboard пока показывает `unavailable`.

## Если установлен Git

Вместо скачивания ZIP можно выполнить:

```powershell
git clone https://github.com/PANDORA615/Netwatch-Terminal.git
cd Netwatch-Terminal
```

Далее выполните шаги создания `.venv`, установки и запуска выше. Для обновления неизменённой локальной копии:

```powershell
git pull --ff-only
.\.venv\Scripts\python.exe -m pip install -e .
```

Если вы меняли код, сначала сохраните свои изменения; при конфликте не удаляйте их. Для ZIP-установки скачайте новую версию в отдельную папку и повторите установку окружения.

## Запуск в Linux

Нужны Python 3.12+, модуль `venv` и графический сеанс. Например, в Ubuntu 24.04:

```bash
sudo apt update
sudo apt install python3 python3-venv libegl1 libopengl0 libxcb-cursor0
```

Скачайте и распакуйте исходники, откройте терминал в папке с `pyproject.toml`:

```bash
python3 --version
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -e .
.venv/bin/python -m netwatch_terminal
```

Проверьте, что версия Python не ниже 3.12. На других дистрибутивах названия системных пакетов могут отличаться.

## Частые ошибки

| Сообщение или ситуация | Что проверить |
| --- | --- |
| `py` не распознано | Установлен ли Python Launcher; заново откройте PowerShell. Попробуйте `python --version` и, если версия 3.12+, `python -m venv .venv`. |
| `No suitable Python runtime found` | Установите Python 3.12 x64 либо укажите установленную версию, например `py -3.13`. |
| `.venv\Scripts\python.exe` не найден | Откройте папку проекта и сначала создайте окружение. |
| `does not appear to be a Python project` | В текущей папке должен быть `pyproject.toml`; возможно, вы открыли внешнюю папку распакованного ZIP. |
| `No module named netwatch_terminal` или `PySide6` | Выполните установку через тот же `.venv\Scripts\python.exe -m pip install -e .`. |
| Окно не появляется, приложение завершается | Запустите через PowerShell, скопируйте полный текст ошибки и приложите версию Windows/Python. |
| Не найдены DLL / `_internal` | Полностью распакуйте готовую сборку; не переносите `.exe` отдельно. |
| Ошибка скачивания pip | Проверьте интернет, настройки прокси и повторите команду. Не отключайте проверку сертификатов. |
| Linux: Qt не загружает `xcb` | Проверьте наличие графического сеанса и системных библиотек Qt/XCB для вашего дистрибутива. |
| Команды терминала ничего не делают | Это ожидаемо для этапов 0–1: пока реализован интерфейс предпросмотра. |

## Разработчикам

Для тестов и сборки нужны дополнительные зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m netwatch_terminal --screenshot docs/terminal-preview.png
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --windowed --onedir --name NetwatchTerminal src/netwatch_terminal/__main__.py --paths src
```

Результат Windows-сборки: `dist\NetwatchTerminal\NetwatchTerminal.exe` вместе с соседними файлами. Собирать Windows-версию нужно в Windows. CI проверяет Windows и Linux, однако проверка на чистой Windows 10/11 отдельно ещё требуется.
