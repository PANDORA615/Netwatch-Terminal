# Возможности и команды 0.2.1

[← На главную](../README.md) · [Установка](INSTALL.md) · [Скриншоты](SCREENSHOTS.md)

Работают Terminal, Dashboard, System, Network, Files, Launcher, BreachLab и Settings. Интерфейс русский/английский, полный экран — F11, выход из полного экрана — Esc. Профили, история (по желанию), избранное и настройки сохраняются в пользовательском каталоге приложения.

## Команды

| Задача | Команды |
| --- | --- |
| Справка и интерфейс | `help`, `clear`, `history`, `breach start` |
| Каталоги | `pwd`, `ls [-a|-l|-la] [path]`, `cd [path]`, `mkdir [-p] <path>`, `rmdir <empty-dir>` |
| Файлы | `touch <path>`, `cat <file>`, `cp <src> <dst>`, `mv <src> <dst>`, `rm <file>` |
| Текст | `head [-n count] <file>`, `tail [-n count] <file>`, `grep [-i] <text> <file>`, `wc <file>`, `sort <file>`, `uniq <file>` |
| Пути и место | `stat <path>`, `du <file>`, `df [path]`, `basename <path>`, `dirname <path>`, `realpath <path>`, `which <program>` |
| Система | `date`, `whoami`, `hostname`, `uname`, `uptime`, `ps`, `kill <pid>` |
| Окружение | `echo <text>`, `env`, `printenv [name]` (без аргумента — имена переменных) |
| Программы | `run <executable> [args]`, `open <path>` |
| Информация без исполнения | `translate <command>`, `explain <command>`, `preview <command>` |

Кавычки группируют пути с пробелами; обратные слеши Windows сохраняются. Команды не поддерживают полный набор флагов GNU, glob, shell-цепочки, пайпы, перенаправления или подстановки. `grep` ищет подстроку, не регулярное выражение. `du` пока только для файлов. `translate` показывает приблизительное имя PowerShell-команды и не выполняет её. `preview`/`explain` описывают операцию, но не симулируют файловую систему.

`run notepad.exe` или `run "C:\Program Files\App\app.exe"` запрашивает подтверждение с путём программы. В Windows допускаются `.exe`; запуск от администратора автоматически не запрашивается. Вывод внешней программы в терминал не перенаправляется; интерактивные CLI-программы в этом режиме не поддерживаются. Приложения с графическим интерфейсом работают отдельно.

Удаление, завершение процессов, запуск программ и открытие файлов требуют подтверждения (по умолчанию отмена). `rm` удаляет один файл без корзины; рекурсия и перезапись отключены. `kill` блокирует системные PID и процессы других пользователей. Файлы читаются как UTF-8, до 1 МиБ. Подробности ограничений — в README.

## Утилиты и настройки

- Реальные CPU/RAM/диск, процессы, сетевые интерфейсы и суммарные RX/TX; обновление раз в 2 секунды.
- Просмотр папок и открытие поддерживаемых файлов.
- Избранные программы с добавлением, удалением из списка и запуском.
- BreachLab: решаемое поле 5×5, чередование столбца/строки, буфер 6 ходов, одна цель, рекорд минимального числа ходов.
- Русский/английский, полноэкранный запуск, история, очистка истории, включение/выключение автозапуска текущего пользователя Windows.

Не реализованы полноценная Linux-среда/WSL, Linux-пакетные менеджеры, история метрик в SQLite, графики, поиск крупных файлов, несколько тем и рекурсивные файловые команды. Веб-предпросмотр — отдельная прежняя демонстрация и не получает доступ к компьютеру.
