## Что работает сейчас

- Desktop-окно PySide6 с оригинальной cyberpunk HUD-темой: лаймовые панели, тонкие рамки, сетка и статичные скан-линии.
- Восемь разделов навигации; Terminal и Dashboard доступны как интерфейс предпросмотра.
- Семь Linux-профилей: Ubuntu, Debian, Fedora, Arch Linux, Kali Linux, openSUSE, Alpine.
- Обновление приглашения, справочной оболочки и подсказок `apt`, `dnf`, `pacman`, `zypper`, `apk` при выборе профиля.
- Поле ввода с Enter и кнопкой Preview: показывает уведомление, не выполняет команды и не сохраняет введённый текст.
- Выделение и копирование текста, прокрутка справки, клавиатурная навигация.
- `Ctrl+1`…`Ctrl+8` — разделы, `Ctrl+L` — фокус на вводе Terminal.
- Автоматические тесты Windows/Linux и тестовая Windows-сборка через GitHub Actions.

## Что пока запланировано

| Функция | Состояние |
| --- | --- |
| Реальные `help`, `clear`, `pwd`, `ls`, `cd`, `cat`, `mkdir` | Следующий этап — безопасный командный движок |
| CPU, RAM и дисковые показатели | Этап 3; сейчас `unavailable` |
| История и сохранение настроек | Пока отсутствуют; профиль действует в текущем сеансе |
| Файловые операции, процессы, сеть, Launcher | Последующие этапы |
| BreachLab | Пока заглушка навигации |

Профиль не устанавливает Linux и не включает WSL или полноценный Bash. Примеры пакетных команд предназначены для справки в реальной Linux-среде. Интерфейс приложения по умолчанию английский. Анимации отключены.
