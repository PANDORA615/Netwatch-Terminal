NETWATCH Terminal 0.2.1 — рабочее desktop-приложение для Windows 10/11 x64.

## Скачать

- **NetwatchTerminal-Setup-x64.exe** — установщик, ярлыки, удаление, необязательный автозапуск Windows.
- **NetwatchTerminal-Windows-x64.zip** — переносимая версия: распаковать всю папку и запустить NetwatchTerminal.exe, сохранив _internal рядом.

Python и администратор для запуска не нужны. Автозапуск выключен по умолчанию; его можно включить и выключить в Настройках. Подпись издателя пока не настроена.

## Новое

Реальные Linux-подобные команды Windows (`help`), запуск `.exe` через `run`, файлы и процессы с подтверждениями, реальные CPU/RAM/диск и сеть, просмотр файлов, избранные программы, решаемая BreachLab, русский/английский, сохраняемые настройки и история по желанию.

Полный экран по умолчанию перекрывает панель задач. **F11** переключает, **Esc** возвращает окно; слева кнопка «Выход».

Это не Linux/WSL и не полный Bash. Пакетные менеджеры, пайпы, перенаправления, рекурсивное удаление не поддерживаются. `run` предназначен для запуска отдельных программ, интерактивный ввод внешних CLI не поддерживается.

Перед релизом CI запускает тесты Windows/Linux, рендер окна, сборку и smoke-тест упакованного `.exe`, компиляцию установщика. Проверка установки/автозапуска на чистой Windows 10/11 отдельно ещё требуется.
