NETWATCH Terminal 0.3.0 — Windows 10/11 x64.

## Новое

- Запуск по короткому имени: **run steam**, run discord, run chrome и другие установленные программы. Поиск через реестр, стандартные папки, PATH и избранное; найденный путь показывается перед подтверждением. Нестандартную установку можно добавить в Программы.
- Короткий глитч-вход, пропускаемый клавишей или кликом.
- Собственные звуки запуска, выбора, успеха и ошибки. В Настройках звук и анимация выключаются независимо.
- BreachLab: матрица 7×7, три последовательности, 60 секунд с первого хода, буфер 6 ходов, решаемая генерация, подсветка целей и доступных ходов.

## Скачать и установить

**NetwatchTerminal-Setup-x64.exe** — установщик. **NetwatchTerminal-Windows-x64.zip** — переносимая версия (распаковать всю папку). Python не нужен. F11 — полный экран, Esc — окно. Автозапуск по желанию в Настройках.

Графика и аудио оригинальные; игровые ассеты не используются. Это не Linux/WSL и не идентичная копия игровой мини-игры. Полноценный Bash и интерактивный ввод внешних CLI не поддерживаются.

CI проверяет Windows/Linux, упакованный exe, наличие звуковых файлов, установку и удаление. Фактическое звучание на пользовательском аудиоустройстве и обнаружение каждого варианта установки сторонних программ требуют ручной проверки.
