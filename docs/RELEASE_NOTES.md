NETWATCH//TERMINAL — переносимая тестовая версия для Windows 10/11 x64.

## Скачать и запустить

1. В Assets скачайте **NetwatchTerminal-Windows-x64.zip** (не Source code).
2. Нажмите правой кнопкой на ZIP → **Извлечь всё**.
3. Запустите **NetwatchTerminal.exe** из распакованной папки. Сохраните рядом `_internal` и остальные файлы.

Python, Git и права администратора для запуска не требуются. На Android/iPhone `.exe` не запускается. Подпись издателя пока не настроена.

## В этой версии

- Cyberpunk HUD-интерфейс и восемь разделов навигации.
- Семь Linux-профилей с подсказками пакетных менеджеров.
- Поле ввода в режиме предпросмотра: команды пока не выполняются.
- Dashboard пока без реальных метрик.

Перед публикацией CI проверяет тесты на Windows/Linux и рендер окна, собирает Windows-приложение. Отдельная проверка на чистой Windows 10/11 пока не выполнена.
